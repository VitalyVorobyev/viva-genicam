# Developing viva-genicam

This book is for people *using* viva-genicam. The documentation for working on
it lives in the repository, next to the code:

- [CONTRIBUTING.md](https://github.com/VitalyVorobyev/viva-genicam/blob/main/CONTRIBUTING.md)
  — building, the checks CI runs, the test suites, the vendor XML corpus, and
  pull requests.
- [docs/](https://github.com/VitalyVorobyev/viva-genicam/blob/main/docs/README.md)
  — the design and its tenets, the standards and which crate implements which,
  decision records, the roadmap and the backlog.
- [studio/README.md](https://github.com/VitalyVorobyev/viva-genicam/blob/main/studio/README.md)
  — building Viva Studio from source.

The most useful contribution needs no code: a report from a camera we have not
seen yet ([Reporting a camera we can't open](reporting.md)).
